    How to read a Market Brief

    Start with the metric dates. Annual financials describe a full fiscal year; the chart shows the latest available daily closes. They are different windows of time.

    Numbers are calculated from provider records. Commentary is labelled as an observation, interpretation or research question. Source checks confirm that references exist; they do not guarantee that an interpretation is correct.

    Sample mode uses invented data and a rule-based brief. Live mode uses SEC records and Alpha Vantage daily prices; Groq writes commentary when configured. Missing data stays missing.

    This app supports research. It does not forecast returns or make trading decisions.
