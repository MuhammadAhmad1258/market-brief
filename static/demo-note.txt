MARKET BRIEF — ILLUSTRATIVE DEMO DATA

All prices, annual financial values, growth rates and financial periods in
sample demo mode are synthetic examples. They do not describe actual NVIDIA,
Apple or Microsoft performance. The fixtures are generated by app/demo.py.

The sample is designed to let you explore the interface without API keys.
Its commentary is rule-based, not generated by Groq. No API calls are made.

Select Live research after configuring the server to use actual SEC
financial records and Alpha Vantage daily prices. Live prices are end-of-day,
unadjusted closes, not a real-time quote feed.
